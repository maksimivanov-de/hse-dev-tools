| Работа | Что проверялось | Задания |
| --- | --- | ---: |
| [Docker](docker-practice/README.md) | Запуск контейнеров, сборка образа, хранение данных MySQL и работа с Redis в сети Docker | 9 |
| [JFrog Artifactory](artifactory/README.md) | Создание репозитория, публикация версий приложения, проверка SHA-256 и поиск артефактов через AQL | 15 |
